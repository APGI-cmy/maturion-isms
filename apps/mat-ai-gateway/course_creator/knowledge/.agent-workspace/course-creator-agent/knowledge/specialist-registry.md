# Course Creator reporting registry

Version: 1.1.0. Effective date: 2026-11-26.

Governance specialist under commissioning issue #2075: `course-creator-agent`, primary domain `course-creation`. Proposed AIMC persona: `course-creator-advisor`, module `course-creator`, capability `document-generation`. These are explicit distinct identity namespaces; only accepted runtime receipts establish their actual mapping.
Required reporting orchestrator: `maturion-agent`. The upstream contract is preserved as read-only source evidence. Its existence is not proof of active runtime registration. The fetched governance registry snapshot has no active agents; it is historical source evidence, not an AIMC persona/runtime registry and not a requirement that a live registry remain empty.

The specialist cannot call a producer, researcher, reviewer or another specialist itself. Maturion and the separately authorised application controller route bounded producer and reviewer work, preserving independence and existing counters. No new subordinate agent is registered by this bundle.

Independent Maturion evaluation appears in the single Maturion chat surface. Its local prototype implementation is an app capability, not evidence of this specialist's activation or AIMC registration. Independent IAA on agent files remains distinct from Maturion's course evaluation.

Do not create a second app-bound Maturion identity. Do not modify the upstream Maturion contract or global registry. `governance/registration-proposal.json` records the exact requested addition for its authorised registry owner.

The existing AIMC persona `course-crafter-advisor` is legacy ISMS-focused instructional advice. It remains unchanged; the generic Course Creator persona must not silently widen that legacy persona or fork Maturion. Registration changes require the appointed owner and actual route acceptance, not a replacement identity string.
