# Portable Course Creator agent submission

Issue: https://github.com/APGI-cmy/maturion-isms/issues/2075

This is an inactive, uninstalled specialist bundle prepared for factory/independent review. Its governance identity is course-creator-agent, proposed AIMC persona course-creator-advisor, reporting to maturion-agent. Existing course-crafter-advisor remains unchanged.

The bundle root is this directory. Tier 1 and Tier 2 references resolve relative to it. Its .github contract is deliberately quarantined here, not installed into the repository agent directory or globally registered. Source snapshots are read-only pinned upstream evidence. The source registry is a historical snapshot, not accepted runtime state.

Local machine paths, protected file inventories, course contents and original app records are excluded. Portable context describes required inputs without embedding private paths. Private producer tools are not exported. The runtime preflight and its isolated signature tests are included; they do not register, invoke or activate a specialist.

Activation remains blocked by independently reviewed runtime gaps: unsigned/structural JWT acceptance at the generic gateway, missing OpenAI document-generation support, and no accepted authenticated Maturion-to-Course-Creator controller route or real commissioning receipt. The central registration candidate stays disabled and gateway invocation is denied.

No learner-guide QA suite or existing QA test was altered. New tests cover only the new inactive registration/preflight. LU2 and held course jobs remain untouched.
