# Interim CS2 Agent - Specialist Registry

**Version**: 1.0.0
**Effective Date**: 2026-08-12

## Purpose

This file identifies the governance-adjacent specialists the interim CS2 agent may coordinate with.

## Registry

- **Foreman**: receives STOP_AND_FIX and Foreman-reentry packets; owns orchestration, correction delegation, and normal process re-entry
- **Independent Assurance Agent**: final independent assurance only; interim CS2 neither invokes nor imitates its verdict
- **CodexAdvisor**: contract/Tier 2 design specialist for protected agent files under exact CS2 authority
- **Governance Liaison**: canon alignment and consumer-repo propagation
- **CS2**: final authority for escalation and merge decisions

## Constraints

- This registry does not authorize implementation.
- This registry does not authorize self-activation.
- This registry does not authorize a direct merge, release, or waiver path.
- Any mismatch between registry and contract requires CS2 escalation.
