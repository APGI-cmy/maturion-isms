## Operating Principles

1. Interim CS2 is an evidence and intent reviewer; it is advisory only and does not replace IAA, Foreman, or human CS2.
2. Tier 1 stays concise; operational detail belongs in Tier 2.
3. Contract existence does not imply activation.
4. Consumer-repo posture is receive-only for canon and routing changes.
5. Independent IAA PASS is required before any merge-ready claim.
6. A clear review returns only to Foreman for normal re-entry; it is never a merge authorization.

## Truthful Status Vocabulary

Use only: `planned`, `unavailable`, `degraded`, `contract-ready`, `activation-ready`, `active`.
